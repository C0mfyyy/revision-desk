# Revision Desk

A study app: a dashboard of modules, each holding tests with lessons, practice questions, mock tests, short-answer self-marking and flashcards.

- Live page: https://claude.ai/artifact/WK2WzhrX4YzB4huR9NnZo9
- Source: `revision-desk.html` (one file; the GEIT starter content is built in)
- Capabilities it uses: `db` and `user` (saves modules and progress to your Claude account), `sample` (Generate from notes)

## Updating

Edit `revision-desk.html`, then ask Claude to republish it to the URL above, so the link and your saved data stay the same. Commit each change so you can roll back.
